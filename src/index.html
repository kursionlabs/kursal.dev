A different set of tools

Make the important things visible.

Kursal makes ownership and access part of the program you write. Its compiler checks those rules before producing C.

01 / OWNERSHIP
!

Values with one owner

A type ending in ! is linear. The language checks that each such value is consumed exactly once across branches and loops.

Understand ownership ↗
02 / ACCESS
&

Permission in the type

Capabilities describe who can access a resource. Place lending passes access through a call without hiding it in global state.

Explore capabilities ↗
03 / OUTPUT
{ }

A narrow path to C

Source is lowered to KURS, checked, and emitted as C. The compiler itself is written in Kursal and builds itself.

In practice

Small syntax.
Explicit intent.

Linear types are spelled at the declaration. A function that receives one must use it, and a loop that consumes one must replace it before the next iteration.
